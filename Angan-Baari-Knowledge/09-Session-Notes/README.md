# Session Notes

Dated notes worth keeping *beyond* what claude-mem captures automatically (claude-mem is local-only, session-observational, and lives in `~/.claude-mem/` — not version-controlled, not meant to be read directly). Use this folder when something from a session is worth a permanent, human-readable record — e.g. `2026-09-27-inventory-bug-hunt.md` — not for routine work already covered by git history or `03-Decisions/Decision-Log.md`.
